【What does this software do?】
When your camera shoots "JPG + RAW" dual format, each photo is saved as two
files. After culling, the folder often ends up with "orphan" files:
  · JPG without RAW  ->  orphan JPG
  · RAW without JPG  ->  orphan RAW
This tool finds those orphans automatically and, after your confirmation,
moves them to the Windows Recycle Bin, so nothing is lost permanently.

It also includes a separate Photo Organizer that files photos away by format,
camera brand, photo orientation, or capture date. The organizer never deletes
anything; it only moves or copies files.

【Requirements】
  · Windows 10 / 11. The exe runs directly - no installation needed.
  · Native C++/Win32 program: zero runtime dependencies, one portable exe,
    instant startup, full high-DPI scaling support.
  · Rebuilding from source: run build.ps1 inside the cpp\ folder (a w64devkit
    compiler is bundled - no dev environment needed). The legacy Python source
    is still included and needs Python 3.10+ with Pillow.

  · Manual install: double-click KILL-STAR SX Root CA.cer -> Install
    Certificate -> Current User -> Place all certificates in the following
    store -> Browse -> Trusted Root Certification Authorities -> Finish.
  · Only this one certificate is needed, and later app updates do not require

【Quick start (3 steps)】
  1. Click "Browse..." and pick a photo folder - scanning starts automatically.
  2. Check the orphan list (or the pair-comparison view) and uncheck anything
     you want to keep.
  3. Click Delete, then the round "Delete" button in the confirm window - done.
  (Only want to file JPG and RAW apart without deleting anything? Click
  "Organize" in the app bar - see the next section.)

【Photo Organizer (v6.1, four modes in v6.2)】
  A separate window opened from the "Organize" button in the app bar. It does
  NOT pair, clean, or delete anything: it only moves or copies JPG / RAW /
  video files into folders you define.

  Four ways to organize:
    ① By format (default)
       JPG -> JPG folder, RAW -> RAW folder, video -> VIDEO folder.
    ② By camera brand
       RAW is split further by brand and extension, e.g. RAW(RW2Panasonic);
       video still gets its own folder.
    ③ By photo orientation
       Landscape / portrait / square, into three folders or two.
    ④ By capture date
       Year / month / week / day, or one specific day.

  Common options:
  · Source folder - defaults to the folder currently open in the main window.
  · Destination root - where the new category folders are created. Leave it
    empty to create them inside the source folder, or pick another location.
  · JPG / RAW / VIDEO destination - rename the folder, or type a full path to
    send one category somewhere else entirely.
  · RAW folder naming (brand mode only) - five patterns: extension + brand
    (default, RAW(RW2Panasonic)), extension only (RAW(RW2)), brand in
    parentheses (RAW(Panasonic)), brand only (Panasonic), extension only (RW2).
    The example next to the option updates live. Brand names follow the UI
    language, so German UI produces German brand names.
  · Copy (keep originals) - off by default (files are moved).
  · Include subfolders - off by default; turn on to process subfolders too.

  Orientation mode in detail:
  · The decision uses the PROPORTIONS AFTER EXIF ORIENTATION IS APPLIED, not
    the raw pixel order - a 4:3 photo shot vertically is not treated as
    landscape.
  · Three folders: Landscape + Portrait + Square.
  · Two folders: only Landscape + Portrait. Square photos go into whichever one
    you click on the two shape cards; "Start Organizing" stays DISABLED until
    you choose, and the app never decides for you.
  · The three shapes are drawn at fixed ratios (3:2 landscape, 2:3 portrait,
    1:1 square) with the caption below the shape, so the portrait silhouette
    can never be squashed into a square just to fit text.
  · A hint strip under the cards spells out the mapping, e.g.
    "Landscape photos -> Landscape folder"; in two-folder mode the square entry
    follows your choice and shows a warning color until you pick one.

  Date mode in detail:
  · Folder names: YYYY (2026), YYYY-MM (2026-11), YYYY-Www (2026-W45),
    YYYY-MM-DD (2026-11-04). "Specific day" only organizes that one day and
    leaves everything else where it is.
  · Weeks use ISO 8601: Monday is the first day, week 1 contains January 4, and
    dates near a year boundary belong to their ISO week-year - 2027-01-01 goes
    to 2026-W53 and 2024-12-30 goes to 2025-W01. The app has only this one week
    algorithm, and a one-line note appears under the option when it is selected.
  · Dates are read in the existing priority order: photo EXIF -> video
    container creation time (MP4 / MOV / MKV headers, AVI ICRD, UTC converted
    to local) -> file timestamp. Files without a readable date can either go to
    a separate "unknown date" folder or be skipped; the preview marks the source.

  Preview and workflow (no separate Preview button - it is always live):
  1. Choose the options. The preview recalculates as you change source,
     destination, mode, naming, or any other setting.
  2. Review the plan. The summary shows total files, total size and folder
     count; each destination gets a card with its path, file count, size,
     JPG/RAW/VIDEO breakdown, sample filenames and a proportion bar.
     Previewing only reads file information.
  3. Click "Start Organizing" and check the confirmation summary (folders to be
     created, files to be processed) before continuing.
  4. Read the result card: how many files were moved or copied, and every
     failure with its reason. Returning to the main window rescans automatically.

  Safeguards:
  · No silent overwrite: an existing different file with the same name gets a
    numbered suffix, e.g. IMG_0001 (1).JPG.
  · Files already in their intended destination are skipped, so re-running the
    same task is safe.
  · A destination nested inside the source is excluded from the scan, so files
    that were just organized are not picked up again.
  · .DNG is shared by several brands and is grouped as RAW(DNG) in brand mode.
  · One failed file never aborts the batch; each failure is reported.

【Two interfaces (your choice)】
  The "View" drop-down in the top bar switches between two layouts; the choice
  is remembered:
  · Classic list - shows only the orphan files that would be processed.
  · Pair compare - shows the JPG and its same-named RAW SIDE BY SIDE on one
    row so the missing side is obvious at a glance:
      - both present  -> row marked GREEN  (complete, row cannot be checked)
      - JPG missing   -> row marked YELLOW (RAW only, the RAW is an orphan)
      - RAW missing   -> row marked RED    (JPG only, the JPG is an orphan)
    Columns: Delete | JPG file (left) | RAW file (right) | Folder | Status |
    Action. The missing side is left blank (no dash placeholder).
    The "Action" column states plainly whether the row WILL be deleted:
      - Delete                     -> orphan and checked; goes to the bin
      - Keep - unchecked           -> you unchecked it, so it stays
      - Keep - paired              -> both sides exist, nothing to do
      - Keep - format not matched  -> RAW extension outside the selected
                                      brand/filter and therefore protected
    Example: with 5 candidate photos, switching the brand to "Panasonic" leaves
    only 2 participating pairs. The classic list shows just those 2, while the
    pair view still lists everything and marks the rest as
    "Keep - format not matched".
    Two switches at the top right:
      - "Mark by background" (default ON): the row background is colored while
        the font color stays the theme color; turn it off to color the TEXT.
      - "Only missing": hide complete pairs and show only problem rows.
    Click a column header to sort by JPG file / RAW file / Folder / Status /
    Action (click again to reverse; ▲/▼ shows the direction). Default order is
    Missing RAW -> Missing JPG -> Complete. The status legend at the top is
    clickable: click "Complete", "Missing RAW" or "Missing JPG" to filter, and
    click the same entry again to clear it. The legend shows live counts.
    Column widths adapt to the window so all six columns stay visible, and each
    column has a minimum width equal to its header text.
    Checkboxes, delete counts, EXIF, preview linkage, reveal-in-Explorer and
    select-all behave identically in both interfaces.

     - Header row 1: "Photo Preview" title on the left, "Detailed EXIF" button

【Confirmation window (misclick-safe)】
  · No system title bar, therefore NO "×" close button;
  · Two round buttons: neutral "✕" (Cancel) on the left, red "✓" (Delete) on
    the right; pressing one fills it solid;
  · Esc and Enter both mean CANCEL, and focus starts on Cancel;
  · Deleting requires an explicit mouse click on the round Delete button.

【Pairing rules】
  · The file name without its extension is the "base name".
  · Same base name with both JPG and RAW -> paired, not deleted.
  · JPG only -> orphan JPG; RAW only -> orphan RAW.
  · Case-insensitive: P10001.JPG and P10001.RW2 are paired.
  · In recursive scans, same-named files in different subfolders also pair.

【Deleting & safety】
  · Delete = move to the Windows Recycle Bin; restorable at any time.
  · The confirmation dialog states: "Files will be moved to the Recycle Bin and
    can be restored."
  · When the RAW format is unmatched, a mandatory confirmation is always shown.
  · A single failed file never interrupts the batch; reasons are listed in the
    Result area. Locked files are retried once.
  · After deletion the app rescans automatically.
  · The organizer never deletes: it moves by default, or copies when "Copy
    (keep originals)" is on. Check the preview and summary before starting.

【FAQ】
  1. Some files fail to delete?
     Usually the file is open in another program. Close it and try again.
  2. Preview area is empty?
     Nothing would be deleted in the current mode; corrupted images are skipped
     and counted.
  3. "RAW format does not match the selection"?
     Switch "Camera Brand" back to Auto-detect.
  4. No EXIF shown when I click a photo?
     JPGs must contain EXIF data; a few RAW formats (e.g. X3F) cannot be parsed.
  5. Can I get deleted files back?
     Yes - everything is moved to the Recycle Bin.
  6. The UI language is not what I want?
     Pick one in the language dropdown; the choice is remembered. On first launch
     it follows the system UI language.
  7. I want to keep some photos?
     Uncheck them (list checkbox / thumbnail badge / Space key).
  8. The UI is too bright/dark?
     Use the "Theme" button in the top bar.
  9. Does the organizer delete anything?
     No. It only moves or copies files between folders.
 10. Where do square photos go in two-folder mode?
     Into the landscape or portrait folder you click. Until you choose,
     "Start Organizing" stays disabled.
 11. Why does a week number belong to the previous year?
     That is ISO 8601: the date belongs to its ISO week-year, which can differ
     from the calendar year (2027-01-01 -> 2026-W53).
 12. My antivirus flags the app even after installing the certificate?
     The certificate only tells Windows who published the app; it cannot
     guarantee an antivirus verdict. If it is a false positive, whitelist the
     app or report it to the vendor.

【Troubleshooting: the app does not start】
  · The program is code-signed; a plain double-click normally starts it.
  · If Windows still shows a security prompt, click "More info" -> "Run anyway".
  · If the certificate installer does not respond, right-click 安装证书.bat ->
    Properties -> tick "Unblock" at the bottom -> OK, then run it again.
  · 1080p / 2K / 4K displays and 100%-200% scaling are all supported; if text
    looks truncated, make the window wider and check for a newer version.
