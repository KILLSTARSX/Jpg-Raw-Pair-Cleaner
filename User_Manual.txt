【What does this software do?】
When your camera shoots "JPG + RAW" dual format, each photo is saved as two
files. After culling, the folder often ends up with "orphan" files:
  · JPG without RAW  ->  orphan JPG
  · RAW without JPG  ->  orphan RAW
This tool finds those orphans automatically and, after your confirmation,
moves them to the Windows Recycle Bin. Deleted files can be restored from
the Recycle Bin, so there is no risk of losing them.

【Requirements】
  · Windows 10 / 11. The exe runs directly - no installation needed.
  · v6.0 is a native C++/Win32 program: zero runtime dependencies, a single
    exe of only ~620 KB, instant startup, and full high-DPI scaling support.
  · Rebuilding from source: run build.ps1 inside the cpp\ folder (a w64devkit
    compiler is bundled - no dev environment needed). The legacy Python source
    is still included and needs Python 3.10+ with Pillow.

【Quick start (3 steps)】
  1. Click "Browse..." and pick a photo folder - scanning starts automatically.
  2. Check the orphan list (or the pair-comparison view) and uncheck anything
     you want to keep.
  3. Click Delete, then the round "Delete" button in the confirm window - done.

【Two interfaces (your choice)】
  The "View" drop-down in the top bar switches between two layouts; the choice
  is remembered:
  · Classic list - shows only the orphan files that would be processed
    (the v5.0 layout, unchanged).
  · Pair compare - shows the JPG and its same-named RAW SIDE BY SIDE on one
    row so the missing side is obvious at a glance:
      - both present  -> row marked GREEN  (complete, nothing to do; row cannot
        be checked)
      - JPG missing   -> row marked YELLOW (RAW only, the RAW is an orphan)
      - RAW missing   -> row marked RED    (JPG only, the JPG is an orphan)
    Columns: Delete | JPG file (left) | RAW file (right) | Folder | Status |
    Action. The missing side is simply left blank (no dash placeholder).
    The "Action" column states plainly whether the row WILL be deleted, so a
    fully-listed table is never ambiguous:
      - Delete                     -> the file is an orphan and checked; it will
                                      be moved to the Recycle Bin
      - Keep - unchecked           -> you unchecked it, so it stays
      - Keep - paired              -> both sides exist, nothing to do
      - Keep - format not matched  -> the RAW extension is outside the selected
                                      brand/filter and is protected
    Example: with 5 candidate photos, switching the brand to "Panasonic" leaves
    only 2 participating pairs. The classic list shows just those 2, while the
    pair view still lists everything and marks the rest as
    "Keep - format not matched".
    Two switches at the top right:
      - "Mark by background" (default ON): the whole row background is coloured
        while the font colour stays the same as the theme; turn it off to colour
        the TEXT instead and keep the background unchanged.
      - "Only missing": hide complete pairs and show only problem rows.
    Click a column header to sort by JPG file / RAW file / Status / Action
    (click again to reverse). Column widths adapt to the window so all six
    columns stay visible; each column also has a minimum width equal to its
    header text, so dragging a column as narrow as possible never covers or
    cuts off the header text above (true for both the classic and pair views). A legend shows live counts, e.g. "Total 10 pairs: complete 2 ·
    missing RAW 3 · missing JPG 5".
    Checkboxes, delete counts, EXIF, preview linkage, reveal-in-Explorer and
    select-all behave identically in both interfaces.

【Interface】(v6.0 modern rounded-card layout, light/dark theme, DPI scaling)
  Top bar: app name on the left; theme, language switch and "About" on the right.
  · Theme: the button shows the CURRENT theme (Light / Dark); clicking switches
    to the other one. Default follows the system. All buttons, drop-downs, cards,
    scrollbars and the slider use rounded / pill shapes.
  · Drop-downs (camera brand / scan scope / language) are custom-drawn: the
    selected value appears immediately, with no "blank until you click
    elsewhere" glitch.
  · Language: 10 languages (English / 简体中文 / 繁體中文 / 日本語 / 한국어 /
    Français / Deutsch / Español / Русский / Português). On first launch the
    system language is detected automatically (Chinese systems use Simplified
    or Traditional); afterwards your own choice is remembered. The label shows
    "Language" in Chinese UI and "语言" otherwise, so users of any language can
    find it. Switching applies instantly - no restart needed.
  ① Target folder: rounded input box + "Browse..." button. Browsing starts
     scanning automatically.
  ② RAW format ("Camera Brand" dropdown, label on the same row):
     - Auto-detect (default): the app detects the RAW formats actually present
       in the folder. Easiest option. After a scan the suffix box shows the
       suffixes it actually FOUND (e.g. .RW2 .NEF), so you can confirm at a
       glance that the right formats were picked up.
     - Pick a brand: the suffix box fills in that brand's suffixes
       (e.g. Sony -> .ARW .SR2 .SRF).
     - Custom: choose this to specify formats yourself. Type suffixes in the
       box, separated by commas (semicolons or spaces work too), e.g. .rw2,.dng;
       the leading dot is optional (rw2 works as well). If you leave it empty
       and click Scan, every known RAW suffix is used and the status bar says so.
     - When you can type in the box (v6.0): only in "Custom" mode - then the
       box has a brighter background and clear text. With Auto-detect or a
       brand selected the background darkens and the text greys out: the box
       is for SHOWING suffixes only (what auto-detect found, or the brand's
       list), not for typing. The old "RAW suffix cannot be empty" popup is gone.
     - Switching modes (v6.0): once a folder has been scanned, switching to
       Auto-detect or another brand re-scans immediately and refreshes the
       suffix box and the list; "Custom" waits until you type and click Scan.
     - Protection: if the selected format does not match what is actually in
       the folder, the status bar warns you and those RAW files are NOT listed
       as orphans (prevents accidental deletion).
  ③ Scan scope: current folder only (default) / 1st-level subfolders /
     2nd-level subfolders / all subfolders.
  ④ Delete mode: orphan JPG only / orphan RAW only / all orphans.
  ⑤ Orphan list: a checkbox column first, then name, type, size, folder.
     - Click a column header to sort; double-click a row to reveal the file in
       File Explorer; single-click a row to view its EXIF;
     - Clicking a row also scrolls the preview to that thumbnail and
       highlights it (list <-> preview linked navigation).
  ⑥ Checkboxes (delete / keep) - new in this version:
     - All files are CHECKED by default, which means "will be deleted";
     - Uncheck the photos you want to keep (☑ -> ☐) by clicking:
       the checkbox in the list, the badge in the top-right of a thumbnail,
       or by pressing Space with rows selected;
     - A single "All / None" pill button sits in the "Orphan Files" card header
       (same row as the list title) and toggles between select-all and
       select-none automatically;
     - Unchecked rows look dimmer; the thumbnail badge becomes an empty box.
     - The badge is intentionally minimal: a rounded box with a check inside
       (just the empty box when unchecked). Box and check are white with a thin
       dark outline, so they stay readable on both bright and dark photos and
       never cover the image.
     - JPG and RAW thumbnails use the EXACT same badge style, so the check state
       is obvious at a glance;
     - The Delete button counts and sizes ONLY the checked files;
     - The confirm window also reports "Excluded (kept): N file(s)";
     - Your check state is remembered for the next scan of the same files.
  ⑦ Photo preview: shows the files that will be deleted.
     - Slider adjusts thumbnail size: Small 120 / Medium 200 / Large 320 px.
     - Single-click a thumbnail to view EXIF; double-click to reveal in File
       Explorer.
     - Brief EXIF (default): one compact line
       Camera | f-stop | Shutter | ISO | Focal length | Resolution
       (e.g. Sony A7M4 | f1.8 | 1/200 | ISO100 | 50mm | 6000x4000).
     - Detailed EXIF: click the "Detailed EXIF" button. Fixed 9 fields - Make,
       Model, Aperture, Shutter, ISO, Focal length, Date taken, Resolution,
       Lens. Missing fields show "--"; JPG and RAW look identical. The EXIF text
       occupies its own full-width row, right-aligned and indented, so it can
       never be hidden by the button (it used to be squeezed away in narrow
       windows - fixed).
     - Copy EXIF: double-click the EXIF area, or use the right-click menu.
     - RAW files support EXIF too (embedded TIFF parsing; a few formats such
       as X3F cannot be read).
     - The preview scrolls back to the top when you switch folders.
     - Scrollbars and the thumbnail-size slider are custom-drawn: the scrollbar
       thumb is a ROUNDED RECTANGLE (semicircular ends, not an ellipse) with a
       very light track; hover to darken, drag it, click the track to page, and
       the mouse wheel works too.
     - List (vertical + horizontal), preview and result areas all share exactly
       the same scrollbar style.
     - When list content (e.g. a long folder path) is wider than the view, the
       horizontal scrollbar below the list scrolls properly.
     - The list and preview areas split the height proportionally and re-adjust
       on every window resize; the divider can be dragged and its ratio is
       remembered, so neither area is ever squeezed into a thin strip.
  ⑧ Confirm before delete: checked by default - a confirmation window appears
     before deleting.
  ⑨ Delete button (red): shows the count and total size, e.g.
     "Delete (7, 24.6 KB)"; becomes "Force Delete" when the RAW format is
     unmatched (confirmation is then mandatory).
  ⑩ Result area: log of scans and deletions (success/failure counts and
     failure reasons).
  ⑪ About: version, author, changelog and the "completely free and open
     source" statement (follows the UI language). The window sizes itself to
     its content and scrolls when the changelog is long; close it with the
     "×" in the title bar or with Esc / Enter - you are right back in the
     main window.

【Confirmation window (misclick-safe)】
  · The confirm window has no system title bar, therefore NO "×" close button;
  · Two round buttons: neutral "✕" (Cancel) on the left, red "✓" (Delete) on
    the right; pressing one fills it solid for clear feedback;
  · Esc and Enter both mean CANCEL, and focus starts on Cancel, so pressing
    Enter never deletes by accident;
  · Deleting requires an explicit mouse click on the round Delete button.

【Pairing rules】
  · The file name without its extension is the "base name".
  · Same base name with both JPG and RAW -> paired, not deleted.
  · JPG only -> orphan JPG; RAW only -> orphan RAW.
  · Case-insensitive: P10001.JPG and P10001.RW2 are paired.
  · In recursive scans, same-named files in different subfolders also pair.

【Deleting & safety】
  · Delete = move to the Windows Recycle Bin; restorable at any time.
  · The confirmation dialog clearly states: "Files will be moved to the
    Recycle Bin and can be restored."
  · When the RAW format is unmatched, a mandatory confirmation is always
    shown, even if "Confirm before delete" is unchecked.
  · A single failed file never interrupts the whole batch; failure reasons
    are listed in the Result area. Locked files are retried once.
  · After deletion the app rescans automatically and refreshes the list and
    preview - no manual steps needed.

【Settings memory】
The app remembers: last folder, RAW format, scan scope, confirm checkbox,
thumbnail size, window position/size, the UI LANGUAGE, the LIGHT/DARK THEME
and your CHECK STATE (files marked as "keep"). Restored on next launch.
Config file: %APPDATA%\相机照片筛选工具\config.json

【FAQ】
  1. Some files fail to delete?
     Usually the file is open in another program (e.g. a viewer). Close it
     and try again.
  2. Preview area is empty?
     Nothing would be deleted in the current mode; corrupted images are
     skipped and counted.
  3. "RAW format does not match the selection"?
     Switch "Camera Brand" back to Auto-detect.
  4. No EXIF shown when I click a photo?
     JPGs must contain EXIF data; a few RAW formats (e.g. X3F) cannot be
     parsed and show "--".
  5. Can I get deleted files back?
     Yes. Everything is moved to the Recycle Bin - restore from there.
  6. The UI language is not what I want?
     Pick one in the language dropdown (10 languages, shown natively); the
     choice is remembered. On first launch it follows the system language.
  7. I want to keep some photos?
     Uncheck them (list checkbox / thumbnail badge / Space key); the counts on
     the Delete button update, and the state is remembered.
  8. The UI is too bright/dark?
     Use the "Theme" button in the top bar (default follows the system).
  9. The suffix box is grey and won't let me type?
     That is by design: the box is editable only in "Custom" mode. With
     Auto-detect or a brand selected it just DISPLAYS the suffixes and cannot
     be edited. Switch to "Custom" to type your own.

【Troubleshooting: the app does not start】
  · The program is code-signed, so normally a plain double-click starts it.
  · If your PC still shows a Windows security prompt, click "More info" ->
    "Run anyway" - it does not affect usage and does not mean anything is wrong.
