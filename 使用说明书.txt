【这个软件是做什么的？】
相机设成"JPG + RAW 双格式"拍照时，同一张照片会同时生成 JPG 和 RAW 两个文件。
挑选、删除照片后，文件夹里经常留下"孤零零"的文件：
  · 只有 JPG、没有 RAW　→　孤立 JPG
  · 只有 RAW、没有 JPG　→　孤立 RAW
本软件自动找出这些孤立文件，经您确认后【移入 Windows 回收站】。
删除的文件可以从回收站恢复，不怕误删。

【运行环境】
  · Windows 10 / 11，双击 exe 即可运行，无需安装任何软件。
  · v6.0 起为 C++/Win32 原生程序：无任何运行时依赖，单文件 exe 仅约
    620 KB，启动瞬间完成，并完整支持高分辨率屏幕的 DPI 缩放。
  · 想自行重新构建：进入 cpp\ 目录运行 build.ps1（内附 w64devkit 编译器，
    无需安装任何开发环境）。旧 Python 源码仍保留，需 Python 3.10+ 与 Pillow。

【快速上手（三步）】
  1. 点"浏览…"选择照片文件夹 → 自动开始扫描。
  2. 在"孤立文件列表"（或"配对对比"）里检查要删除的文件（不需要删的取消勾选）。
  3. 点"删除"→ 在弹出的确认窗口中点圆形"删除"按钮 → 完成。

【两种界面（可自主选择）】
  顶部应用栏左侧的「界面」下拉框可在两种界面之间切换，选择会被记住：
  · 经典界面：只列出要被处理的孤立文件（v5.0 的老界面，保持不变）。
  · 对比界面：把同一张照片的 JPG 与 RAW【并排显示在同一行】，一眼看出缺哪边：
      - 两侧都有 → 行标【绿色】，说明已配对，无需处理（该行不能勾选）；
      - 只缺 JPG → 行标【黄色】（只有 RAW，RAW 是孤立文件）；
      - 只缺 RAW → 行标【红色】（只有 JPG，JPG 是孤立文件）。
    表格列为：删除 | JPG 文件（左） | RAW 文件（右） | 所在文件夹 | 状态 | 处理；
    缺失的一侧直接留空（不再显示横杠），左右对照非常直观。
    「处理」列会明确写出这一行【会不会被删除】，避免"全部显示却分不清"：
      - 删除：有孤立文件且已勾选，点删除即移入回收站；
      - 不删除 · 已取消勾选：您主动取消勾选，保留不删；
      - 不删除 · 已配对：两侧齐全，本来就不需要处理；
      - 不删除 · 格式未匹配：该 RAW 后缀不在本次参与配对的格式内（品牌 / 自定义
        筛选导致），受保护不会被删除。
      例：文件夹里共 5 张待处理照片，把相机品牌切成"松下"后只剩 2 张参与配对——
      经典界面只显示这 2 张；对比界面仍列出全部，但另外几张的「处理」列写着
      "不删除 · 格式未匹配"，一眼就能区分该删的与不该删的。
    右上角两个开关：
      - 「用背景色标记」（默认开）：整行底色变色，字体颜色保持与主题一致不变；
        关掉它则改为"字体颜色变色、底色不变"（即第二种标记方式）。
      - 「只显示缺失」：勾选后隐藏配对完整的行，只看有问题的照片。
    点表头可按 JPG 文件名 / RAW 文件名 / 状态 / 处理排序（再点一次反向）。
    列宽会随窗口宽度自动调整，六列始终完整可见；
    手动拖动列宽时，最小只会缩到"刚好完整显示表头文字"的宽度，
    不会把上方表头文字遮住或截断（经典界面同样适用）。
    顶部图例实时显示：共 N 组：齐全 x · 缺 RAW y · 缺 JPG z。
    勾选、删除统计、EXIF、相片预览联动、双击定位、全选/全不选在两种界面上完全一致。

【界面说明】（v6.0 现代圆角卡片界面 + 深浅色主题 + DPI 缩放）
  顶部应用栏：左侧为软件名；右侧依次为界面、主题、关于与语言切换。
  · 主题：按钮显示【当前】主题（浅色 / 深色），点击即切换到另一种，默认跟随系统；
    所有按钮、下拉框、卡片、滚动条均为圆润的药丸 / 圆角造型。
  · 下拉框（界面 / 相机品牌 / 扫描范围 / 语言）为自绘样式：点开后选择，数值会【立即显示】，
    不会出现"选完空白、需要再点一下别处才显示"的情况。
  · 语言：下拉框共有 10 种语言（English / 简体中文 / 繁體中文 / 日本語 /
    한국어 / Français / Deutsch / Español / Русский / Português）。
    首次启动会按系统语言自动选择（中文系统自动用简体或繁体），之后以您的
    手动选择为准。标签在中文界面显示 "Language"、其他语言显示"语言"，
    任何语言的用户都能找到入口。切换后【实时生效】，无需重启。
  ① 目标文件夹：圆角输入框 + "浏览…"按钮。用"浏览…"选好文件夹后会自动扫描。
  ② RAW 格式（标签"相机品牌"，与下拉框同行显示）：
     - 自动识别（默认）：程序自己探测文件夹里实际存在的 RAW 格式，最省事。
       扫描完成后，后缀栏会显示这次【实际找到】的 RAW 后缀（如 .RW2 .NEF），
       方便您确认程序找对了格式；
     - 选品牌：后缀栏自动填入该品牌的后缀（如索尼 → .ARW .SR2 .SRF）；
     - 自定义：想自己指定格式时选它，在后缀栏输入后缀，用逗号分隔即可
       （分号、空格也可以），如 .rw2,.dng；开头的小圆点可省略（写 rw2 也行）。
       留空就点"开始扫描"时，会按全部已知 RAW 后缀扫描，并在状态栏说明；
     - 后缀栏什么时候能输入（v6.0）：只有选"自定义"时才能输入，此时
       输入框底色较亮、文字清晰；选"自动识别"或具体品牌时，底色压暗、
       文字变灰，只能看不能改（自动识别显示实际找到的后缀，品牌显示该
       品牌的后缀），也不会再弹"RAW 后缀不能为空"的提示；
     - 切换模式（v6.0）：选好文件夹后，切换"自动识别"或品牌会立即重新
       扫描，后缀栏和列表马上更新；选"自定义"则等您输完后缀、自己点
       "开始扫描"；
     - 保护机制：所选格式与实际格式不符时，状态栏会提示，且这些 RAW
       不会列入孤立文件，防止误删。
  ③ 扫描范围：仅当前文件夹（默认）/ 一级子文件夹 / 二级子文件夹 / 全部。
  ④ 删除方式：只删孤立 JPG / 只删孤立 RAW / 删除全部孤立文件。
  ⑤ 孤立文件列表：首列是勾选框，随后是文件名、类型、大小、所在文件夹
     （隔行浅底色，便于阅读）。
     - 点表头排序；双击行在资源管理器中定位；单击行看 EXIF；
     - 单击行时，下方预览区会自动跳到对应缩略图并高亮它（列表 ↔ 预览联动）。
  ⑥ 勾选（删除 / 保留）——本版新增：
     - 默认【全部勾选】＝这些文件都会删除；
     - 不需要删除的照片请【取消勾选】（☑ → ☐）：
       · 点列表首列的勾选框，或
       · 点缩略图右上角的勾选角标，或
       · 选中列表行后按【空格键】；
     - 也可用"孤立文件列表"标题栏右侧的【全选/全不选】按钮批量切换
       （一个按钮，点击后按当前状态自动在全选 / 全不选之间切换）；
     - 取消勾选的文件行显示更淡，缩略图右上角角标变为"空方框"；
     - 角标样式很简洁：圆角方框 + 方框中间的勾（取消勾选时只剩空方框），
       方框与勾为白色并带深色细轮廓，深浅照片上都看得清，且不遮挡照片；
     - JPG 与 RAW 的角标样式完全一致，勾选状态一眼可辨；
     - 删除按钮上的数量和总大小【只统计仍被勾选的文件】；
     - 确认窗口会额外提示"已排除（保留）：N 个文件"；
     - 勾选状态会被记住，下次扫描同一批文件时仍然保留您的选择。
  ⑦ 相片预览：显示将要删除的文件。
     - 滑块调节缩略图大小：小 120 / 中 200 / 大 320 像素；
     - 单击缩略图看 EXIF，双击缩略图在资源管理器中定位；
     - 简略 EXIF（默认）：一行紧凑显示
       相机 | f值 | 快门 | ISO | 焦距 | 分辨率
       （如 Sony A7M4 | f1.8 | 1/200 | ISO100 | 50mm | 6000×4000）；
     - 详细 EXIF：点"详细 EXIF"按钮切换，固定 9 项——相机厂商、相机型号、
       光圈、快门、ISO、焦距、拍摄日期、分辨率、镜头；
       缺失的字段显示 "--"，JPG 与 RAW 结构完全一致；EXIF 信息单独占一整行、
       右对齐并向右缩进，与按钮永不重叠（窄窗口也能完整显示）；
     - 复制 EXIF：双击 EXIF 区域，或右键菜单选择复制；
     - RAW 文件同样支持 EXIF（内嵌 TIFF 解析；个别格式如 X3F 无法读取）；
     - 切换文件夹后预览自动回到顶部；
     - 滚动条与"缩略图大小"滑块都是自绘样式：滚动条滑块是【长方形、左右/上下两端
       为半圆】的圆角条（不是椭圆），并带极浅轨道，鼠标悬停变深、可按住拖动、
       点击空白翻页、滚轮也可滚动；
     - 列表（竖向 + 横向）、相片预览区、操作结果区的滚动条样式完全一致；
     - 列表内容（如"所在文件夹"路径）超出显示宽度时，列表下方水平滚动条可正常滚动；
     - 列表与预览区的高度按比例自动分配，窗口放大缩小时都会同步调整，
       分隔条可拖动（拖动后的比例会被记住），两个区域都不会被挤成一条。
  ⑧ 删除前二次确认：默认勾选，删除前弹出确认窗口。
  ⑨ 删除按钮（红色）：显示数量和总大小，如"确认删除（7 个，共 24.6 KB）"；
     格式不符时变为"强制删除"（必弹确认）。
  ⑩ 操作结果：扫描与删除的日志（成功/失败统计、失败原因）。
  ⑪ 关于：版本、作者、更新日志，以及"本软件完全免费开源"的声明
     （随界面语言切换）。窗口大小随内容自适应、过长时出现滚动条；
     点标题栏"×"或按 Esc / 回车即可关闭，关闭后即可在主窗口继续操作。

【确认窗口（防误触设计）】
  · 删除前的确认窗口没有系统标题栏，因此【没有"×"关闭按钮】；
  · 两个圆形按钮：左边中性色"✕"（取消），右边危险色"✓"（删除），
    按下时会变成实心填充，反馈明确；
  · 按 Esc 或回车都等于【取消】，默认焦点也在"取消"上，不会回车误删；
  · 删除必须用鼠标明确点击右侧的圆形"删除"按钮。

【配对规则】
  · 文件名去掉扩展名后的部分称为"基础名"；
  · 同一基础名同时有 JPG 和 RAW → 已配对，不删除；
  · 只有 JPG → 孤立 JPG；只有 RAW → 孤立 RAW；
  · 不区分大小写：P10001.JPG 与 P10001.RW2 视为配对；
  · 递归扫描时，不同子文件夹中的同名文件同样参与配对。

【删除与安全】
  · 删除 = 移入 Windows 回收站，可在回收站中还原；
  · 确认弹窗明确提示"文件将移至回收站，可从回收站恢复"；
  · 格式不符时强制二次确认，取消勾选"删除前二次确认"也不会跳过；
  · 单个文件删除失败不中断整体流程，失败原因会在"操作结果"中列出；
    文件被其他程序占用时自动等待后重试一次；
  · 删除成功后自动重新扫描，列表与预览自动刷新，无需手动操作。

【配置记忆】
自动记住上次的设置：文件夹、RAW 格式、扫描范围、二次确认勾选、
缩略图大小、窗口大小与位置、【界面语言】、【浅色/深色主题】、
【勾选状态（哪些文件被设为保留）】。下次启动自动恢复。

【常见问题】
  1. 有的文件删除失败？
     多半是文件正被其他程序打开（如看图软件），关闭后重试即可。
  2. 预览区没有内容？
     当前删除方式下没有要删除的文件；损坏的图片会被跳过并提示数量。
  3. 提示"RAW 格式与所选格式不符"？
     把"相机品牌"切回"自动识别"即可。
  4. 单击照片看不到 EXIF？
     JPG 需本身带 EXIF 信息；个别 RAW 格式（如 X3F）无法解析时显示 "--"。
  5. 删错的文件能找回吗？
     能。所有删除都移入回收站，在回收站中还原即可。
  6. 界面语言不是想要的？
     在顶部的语言下拉框里选一个即可（共 10 种语言，均以母语显示），
     选择会被记住；首次启动自动跟随系统语言。
  7. 想保留某些照片？
     把它们取消勾选即可（列表勾选框 / 缩略图角标 / 空格键），删除按钮
     上的数量会实时更新，选择也会被记住。
  8. 界面太亮 / 太暗？
     点顶部的"主题"按钮切换浅色 / 深色（默认跟随系统）。
  9. 后缀栏是灰的、打不了字？
     正常现象：只有"相机品牌"选"自定义"时后缀栏才能输入；"自动识别"
     和品牌模式下它只用来【显示】后缀，不能修改。想自己输入就切换到
     "自定义"。

【打不开怎么办？】
  · 程序已做代码签名，正常情况下双击即可直接运行。
  · 个别电脑仍弹出 Windows 安全提示时：点【更多信息】→【仍要运行】即可，
    不影响使用，也不是软件有问题。
