## <a id="what-is-an-orphan-file"></a> 🤔 什么是“孤立文件”？

用 JPG + RAW 双格式拍摄时，同一张照片会同时存成两份：JPG 便于浏览分享，RAW 保留更多原始数据方便后期。例如：

```text
IMG_0001.JPG
IMG_0001.CR3
```

如果在相机里挑片、导入时漏了一部分，或者以前手动清过其中一种格式，就可能只剩下单边文件。留下的这一份就是**孤立文件**。

| 文件夹里的情况 | 文件状态 | 软件怎么处理 |
| :--- | :--- | :--- |
| 有 JPG，缺同名 RAW | 孤立 JPG | 列出供检查，确认后才移入回收站 |
| 有 RAW，缺同名 JPG | 孤立 RAW | 列出供检查，确认后才移入回收站 |
| JPG 与 RAW 都在 | 配对完整 | 不会成为可删除对象 |

软件以**文件基础名**（不含扩展名）作为配对依据，扫描范围可以是当前文件夹、指定层级或全部子文件夹。

### 两种清理界面

用应用栏的「界面」下拉框切换，选择写入配置、下次启动沿用。

**经典界面**只列出孤立文件（文件名 / 类型 / 大小 / 所在文件夹），适合快速过一遍要删的文件。

**配对对比界面**把同一张照片的 JPG 与 RAW 放在同一行：

| 配对状态 | 行标记 | 含义 |
| :--- | :--- | :--- |
| 两侧都在 | **绿色** | 配对完整，不可勾选 |
| 有 RAW 缺 JPG | **黄色** | 缺 JPG，RAW 是孤立文件 |
| 有 JPG 缺 RAW | **红色** | 缺 RAW，JPG 是孤立文件 |

对比界面还有：

- **「处理」列**：直接写明这行会不会被删（删除 / 不删除·已取消勾选 / 不删除·已配对 / 不删除·格式未匹配）。
- **可点击的状态图例**：点「齐全」「缺 RAW」「缺 JPG」筛选，再点一次恢复全部，图例实时显示数量。
- **「只显示缺失」**：隐藏配对完整的行。
- **表头排序**：五列都支持，重复点击切换升降序，▲/▼ 指示方向；默认按缺 RAW → 缺 JPG → 配对完整。
- **标记方式可选**：整行背景色或仅文字颜色。

## <a id="quick-start"></a> 🚀 快速开始

到 **[Releases 下载页](https://github.com/KILLSTARSX/Jpg-Raw-Pair-Cleaner/releases/latest)** 下载最新版本。支持 Windows 10 / 11，绿色单文件，无需安装、无需额外运行环境。

> **首次运行提示「未知发布者」？** 这是自签名证书的正常现象。把 [证书.7z](证书.7z) 解压后双击 `安装证书.bat`，按提示装一次即可（只需一次，以后更新不用重装）。不装也能正常使用，只是 Windows 可能多提示一次。

### 清理孤立 JPG / RAW

1. 点「浏览…」选择照片文件夹，软件自动开始扫描。
2. 在经典界面或对比界面检查结果，不想删的取消勾选。
3. 选择删除范围（仅 JPG / 仅 RAW / 全部），点「删除」。
4. 核对确认窗口，明确点「删除」后才移入回收站。

### 整理 JPG / RAW

1. 点应用栏的「分类整理」，打开独立窗口。
2. 选来源文件夹、目标根目录和分类方式（来源默认沿用主界面当前文件夹）。
3. 看自动生成的文件夹卡片与统计，按预期目录结构调整选项。
4. 点「开始整理」，核对确认摘要后执行。

更细的操作说明见 [使用说明书.txt](使用说明书.txt)。

## <a id="photo-organizer"></a> 🗂️ 分类整理（v6.2）

分类整理是一个独立的归档工具：**不做 JPG / RAW 配对、不做孤立文件清理、不删除任何照片**，只按你设的规则移动或复制文件。

### 四种分类方式

| 方式 | 归档规则 | 生成的文件夹 |
| :--- | :--- | :--- |
| **按格式** | JPG / RAW / VIDEO 各归一类，视频单独成类 | `JPG`、`RAW`、`VIDEO` |
| **按相机品牌** | RAW 再按品牌与后缀分子目录，视频单独一类 | `JPG`、`RAW(RW2松下)`…、`VIDEO` |
| **按照片方向** | 按旋转后的显示比例分横屏 / 竖屏 / 正方形 | `横屏`、`竖屏`、`正方形` |
| **按拍摄日期** | 按年 / 月 / 周 / 天或指定某一天分类 | `2026`、`2026-11`、`2026-W45`、`2026-11-04` |

目录名都可以改，也可以直接填完整路径把某一类放到别处；默认目标为来源文件夹本身。

### 按照片方向

判定依据是**按 EXIF Orientation 旋转之后的显示比例**（4:3 的竖拍照片不会因为像素顺序被误判成横屏），不是文件里的原始宽高。

- **三文件夹模式**：横屏、竖屏、正方形各一个目录。
- **两文件夹模式**：只有横屏与竖屏两个目录，正方形照片归入哪一边由你在两张图形卡片中点选；**未选之前不能开始**，软件不会替你决定。

三种分类用固定比例绘制（横屏 3:2、竖屏 2:3、正方形 1:1），并在卡片下方标注名称——竖屏不会再被文字挤成方块。

### 按拍摄日期

| 分类方式 | 文件夹名示例 |
| :--- | :--- |
| 按年 | `2026` |
| 按月 | `2026-11` |
| 按周 | `2026-W45` |
| 按天 | `2026-11-04` |
| 指定日期 | `2026-11-04`（只整理这一天，其余保持原位） |

「按周」采用 **ISO 8601**：周一为一周之始，第 1 周含 1 月 4 日，跨年日期归入其所属的 ISO 周年（`2027-01-01 → 2026-W53`、`2024-12-30 → 2025-W01`），不会用当前年份硬拼周数。软件只有这一套周算法，选中按周时界面会给出一行说明。

日期读取沿用原有优先级：照片 EXIF → 视频容器创建时间（MP4 / MOV / MKV 读头，AVI 读 ICRD，UTC 转本地）→ 文件时间；读不到时间的文件可选择单独存入「日期未知」或跳过，预览里会标注来源。

### 颜色与提示

JPG 与横屏用蓝、RAW 与竖屏用橙黄、正方形用柔和绿、视频用紫，颜色同时体现在文件夹图标、目录标签和占比条上；浅色与深色主题各有一套。方向模式下，卡片下方有一条提示带，直接写出「横屏照片 → 横屏文件夹」这样的对应关系；两文件夹模式里，正方形那一项会跟着你选的归属变色，没选时显示警示色。

### 安全细节

- **不覆盖同名文件**：目标已有同名文件时自动改名，如 `IMG_0001 (1).JPG`。
- **跳过已到位的文件**：已经在目标文件夹里的文件不再搬动，避免重复执行出错。
- **目标目录不参与扫描**：目标在来源内部时，扫描会自动跳过它。
- **DNG 统一归类**：`.DNG` 被多个品牌共用，按品牌分类时统一进 `RAW(DNG)`。
- **失败不中断**：单个文件失败只记录原因，其余继续处理。

## <a id="supported-camera-brands--raw-formats"></a> 📸 支持的相机品牌与 RAW 格式

内置 **15 个相机品牌配置**，品牌名会按界面语言本地化（如 Panasonic 可能显示为 `Panasonic`、`松下 Panasonic`、`パナソニック Panasonic`）。

| 相机品牌 | 可识别的 RAW 后缀 |
| :--- | :--- |
| 松下 Panasonic | `.RW2` |
| 佳能 Canon | `.CR3` / `.CR2` / `.CRW` |
| 尼康 Nikon | `.NEF` / `.NRW` |
| 索尼 Sony | `.ARW` / `.SR2` / `.SRF` |
| 富士 Fujifilm | `.RAF` |
| 奥林巴斯 Olympus | `.ORF` |
| 宾得 Pentax | `.PEF` |
| 适马 Sigma | `.X3F` |
| 三星 Samsung | `.SRW` |
| 理光 Ricoh | `.DNG` |
| 徕卡 Leica | `.DNG` |
| 哈苏 Hasselblad | `.3FR` |
| 飞思 Phase One | `.IIQ` |
| 玛米亚 Mamiya | `.MEF` |
| 利图 Leaf | `.MOS` |

其他规则：

- **自动识别**：检测所选文件夹里实际存在的 RAW 后缀。
- **自定义格式**：可手动填多个后缀，英文逗号分隔，如 `.rw2,.dng`。
- **大小写不敏感**，`.jpg` 与 `.jpeg` 都算 JPG。
- **格式不匹配保护**：所选品牌与实际后缀不符的文件会被保护，不会被当作孤立文件删掉。
- **未知字段显示 `--`**：读不到的 EXIF 不会猜。

## <a id="faq"></a> ❓ 常见问题

| 问题 | 回答 |
| :--- | :--- |
| **清理是永久删除吗？** | 不是，只移入回收站，通常可直接还原。 |
| **配对完整的照片会被误删吗？** | 不会，它们不是可勾选对象。 |
| **分类整理会删文件吗？** | 不会，只移动或复制。 |
| **分类整理时怎么保留原文件？** | 勾「复制（保留原文件）」。 |
| **目标里已有同名文件怎么办？** | 自动改名加编号后缀，不覆盖；已在目标里的文件会跳过。 |
| **两文件夹模式下正方形照片去哪了？** | 去你点选的那个（横屏或竖屏）。没选之前「开始整理」是禁用的。 |
| **按周为什么会出现上一年的周号？** | 这是 ISO 8601 的规定：跨年周归属它所在的那个 ISO 周年。 |
| **RAW 能显示缩略图吗？** | 六个主要品牌的 RAW 可提取内嵌预览；其他格式显示后缀占位框。 |
| **支持哪些格式？** | JPG / JPEG，以及上表列出的 RAW 后缀，还可自定义。 |
| **怎么切换语言 / 主题？** | 应用栏的「语言」「主题」下拉框；语言首次按系统检测，之后以手动选择为准。 |
| **支持哪些系统？** | Windows 10 / 11。 |
| **杀毒软件报毒怎么办？** | 装证书不能保证不误报；确认是误报后请加入白名单或向厂商提交申诉。 |

- **目标位置可自定义**：来源默认沿用主界面当前文件夹，目标根目录默认同源；各类目录名可改，也可直接填完整路径。
- **移动或复制**：默认移动，复制模式保留来源文件，可选是否包含子文件夹。
- **实时方案预览**：执行前汇总文件数量、总大小与目标目录，逐个显示路径、文件分布与示例文件名；确认后执行，并给出成功与失败汇总。
- **安全**：重名不覆盖、自动加编号后缀；已在目标目录中的文件跳过，源目录内的目标文件夹在扫描时排除。
- **配对对比改进**：五列均可双向排序，默认按「缺 RAW → 缺 JPG → 配对完整」排列；点状态图例可直接筛选。
